# 保守的 1–3 音识别实验

[English](CONSERVATIVE.md)

## 目标与当前交付边界

用户要求：单音、双音、三音可以显示；证据不足时不猜、不保留误导性的旧音；扫弦不要显示。第一组真人对照是标准调弦 **D3/G3 空弦，MIDI 50/55**。

这里新增的 `conservative.py` 是**离线 Python 实验，不是已交付的 CLAP 功能**。正式 Guitar Frontend 仍为 0.1.1 单主音版，没有替换、没有重启 REAPER。正式版也不具备本实验的整组拒绝规则。

“绝对正确才输出”不能作为信号算法可保证的条件：两个独立正弦音 f 和 2f，与一个含对应泛音的音，可能产生相同波形；仅凭混合音频无法区分来源。类似地，六弦扫弦可以只包含三个不同音级及重复八度，不能把“检测到三个音”当成“只弹了三根弦”。置信度高也不等于事实正确。

## 当前实验规则

- 不使用已知 D/G 标签、所选和弦或调性限制候选；始终检查 MIDI 38–88。
- 固定 128 ms 因果分析窗、8 ms 步进，Hann 频谱峰值插值；检查基音与至少三个独立谐波证据、半音偏差、频谱解释覆盖率和音调集中度。阈值统一放在 `conservative.toml`，不逐例调参。
- 同组候选稳定五帧才允许输出；这不是校准后的正确概率。纯正弦、缺失基音、强弱悬殊或泛音混淆可能直接拒绝，或者漏掉较弱声部。
- 候选改变或任意检测拒绝时，模拟输出立即清空，不沿用上一组音。分析窗本身仍有延迟；不代表能在物理止音瞬间清空。
- 检测出超过三个独立候选时整组拒绝，并锁定到持续安静后再开放。**检测不全时这项保护可能失效**；没有可靠的演奏动作/扫弦分类器。
- 音符语义为精确 MIDI pitch，不把不同八度合并。重复位置的显示仍交给 Chord Lab，不推测实际弦号和把位。

## 固定合成筛选（2026-10-17）

`target/guitar-conservative/screening.json` 保存完整结果。每个输入使用三个电平、正弦或八阶谐波音色；“曾完整正确 20 ms”是宽松筛选，不是全段通过。

| 同时音数 | 用例 | 曾完整正确 ≥20 ms | 曾出现额外错误音高 | 成功用例最大整组起音延迟 |
|---|---:|---:|---:|---:|
| 1 | 36 | 18 | 0 | 124 ms |
| 2 | 54 | 21 | 0 | 132 ms |
| 3 | 30 | 9 | 0 | 132 ms |

- D、G、D+G、D+G+B 的谐波合成测试在三个电平都得到预期结果；这不是实录验证，也不是只允许识别这几个音。
- 12 组重叠分解没有出现额外错误音高，但不代表完整集合或所有转换正确。
- **24 组应整段拒绝的密集/扫弦输入中有 3 组仍输出了三个音，因此不通过部署门槛。** 例子：G 和弦六弦输入 `[43,47,50,55,59,67]` 被解释成 `[43,47,50]`。这三个音本身存在，但违背了“扫弦整组不显示”的用户规则。
- 120 组中大量用例漏音或完全拒绝，不能只用“错误音高为零”声称成功。没有代表性真人素材、校准概率、CPU 实时保证或 Bitwig 验收。
- 当前实验比正式版更慢，不满足“超级实时”的目标。不能用 FFT 步进 8 ms 冒充端到端延迟。

## 继续前必须完成

1. 用用户标注的 D/G 双音实录检查：起止音、漏音、误报、空白率。随后补单独 D、单独 G，验证不会把泛音当另一个声部；再测试一个已标注三音。不能只测已知答案、把候选锁死为 D/G。
2. 加入多种吉他音色、弱声部、邻接半音、八度、五度、轻微失谐、噪声、四音至六音扫弦及不同起音间隔。同步报告漏检、错误音、错误整组接受和 P50/P95/最大延迟。
3. 在独立测试集通过之前不部署。本次扫弦拒绝失败必须明确保留，不能用单个成功双音替代验收。
4. 如后续引擎达标：将 C++ 的单音 `Observation/Update/current` 扩为固定容量最多三音集合；MIDI 按差集发送 note-off/note-on，拒绝时只释放本前级生成的音，不影响电脑键盘；覆盖宿主拒收事件重试、停止、断开、静音、状态恢复与多实例。继续保持音频透传，不依赖 REAPER API，再分别验收 REAPER 与 Bitwig。

## 复现

依赖 NumPy、Python ≥3.11。未嵌入或修改前一份 PDCT 上游代码。

```sh
mkdir -p target/guitar-conservative
python lib/tools/guitar_poly/screen_conservative.py \
  lib/tools/guitar_poly/conservative.toml \
  lib/tools/guitar_poly/conservative_benchmark.toml \
  target/guitar-conservative/screening.json
python -m pytest -q lib/tools/guitar_poly/test_conservative.py lib/tools/guitar_poly/test_benchmark.py
```
