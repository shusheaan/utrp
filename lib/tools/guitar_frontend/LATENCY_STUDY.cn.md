# 单音优先：延迟与八度回归筛选

[English](LATENCY_STUDY.md)

## 2026-10-17 的目标与决策

用户确认：双音/三音若不可靠，可以不做；先提高单音音高/八度正确性，再尽量降低延迟。不确定时允许不输出，但必须同时报告漏检，不能用沉默冒充准确。需要真人弹奏时先说明弦/品位，等用户确认就绪才开始录制。

**本次仅作离线配置比较，未改正式默认参数、未安装插件、未重启 REAPER。所有加速候选均未获准部署。** 正式仍是 0.1.1，之前“第三/第四弦七八品”的实际八度问题尚未完成带标签实录复测。

## 方法

不修改识别算法；用 `latency_study.toml` 固定六组 frame/hop/stability。每组单独生成配置、编译 detector 测试和离线 replay；不生成 CLAP。编译失败会终止；测试失败完整保留，不跳过、不伪装成通过。

| frame/hop/stability（ms） | 现有 detector 测试 | 合成单音最大起音延迟 |
|---|---|---:|
| 64/8/24，现有基线 | 通过 | 80.25 ms |
| 48/8/16 | 失败：连续旋律插入错误音 | 56.17 ms（仅音高矩阵） |
| 48/4/8 | 失败：连续旋律插入错误音 | 52.15 ms（仅音高矩阵） |
| 40/4/16 | 通过 | 52.15 ms |
| 40/4/8 | 通过 | 44.13 ms |
| 32/4/8 | 通过 | 36.10 ms |

现有测试包含 510 个音高/波形/采样率组合、45 个虚假低音定向用例、噪声/直流/静音拒绝、连续旋律与重复拨弦。**通过这些测试不代表真琴正确或端到端延迟达标。**

## 历史录音推翻“单纯缩窗就够了”的方案

对先前 Spark 录音中 27.9–29.2 秒的已知问题片段作回放。这是混合/留弦信号，不是带标签纯单音素材；即便只承诺单音，遇到这种干扰也不应生成不存在的低音。

表中统计稳定/释放逻辑之后的 `current` 输出状态，而不是原始帧 `observed`。不同 hop 的采样数不同，因此用该区间内的占比比较，不把帧数当成整段录音准确率。

| 配置 | 输出虚假 E2/A2 的状态占比 | 无音状态占比 |
|---|---:|---:|
| 64/8/24 | 0% | 24.69% |
| 40/4/16 | 19.69% | 7.69% |
| 40/4/8 | 20.92% | 7.08% |
| 32/4/8 | 25.54% | 5.23% |

基线原始 `observed` 中仍有一帧 A2，但稳定逻辑阻止它成为输出；之前“误报为零”的结果指该特定片段的 `current` 输出，不是所有分析候选永远正确。短窗口候选不仅错误增多，Release 还可能延长错误输出，因此不能只调小 Stability。

## 更新：Spark GO A3 实录（2026-10-17）

用户确认前面反复弹的是第 4 弦第 7 品，最后是非受控弹奏。本轮只验证当前 0.1.1，没有修改算法、部署插件或重启 REAPER。

- 前 38.2 秒包含重复单音、起音、止音及间隔；输出 A3 3785 个 hop、无音 975 个 hop、A#3 7 个 hop。未出现低八度输出。无音包含刻意止音，不能直接算漏检率。
- 从原始录音选取的 12 个稳态内部区间，共 2601 个 hop，`current` 和 `observed` 均为 MIDI 57。这只说明这些稳态区间通过，不代表整段或其他音高百分之百正确。
- 两次短暂输出 A#3：12.800–12.832 秒、32.080–32.104 秒。原始波形上升过零的相邻周期在此前也短暂变短，等效周期频率约 233–248 Hz，随后回到约 220 Hz。因此不能断言是算法凭空跳音；松手/止音瞬态及波形变化需要区分。过零统计本身也不是精确音高真值。
- 10 次人工检查的分离起音，按原始 5 ms RMS 块越过 −48 dBFS 到离线 `current=A3` 的时间粗测约 60–86 ms。阈值法不是实际拨弦时刻，未包含接口、宿主、界面延迟，不能宣称 MIDI 键盘级响应。自动阈值候选中还有止音回弹和原本已激活的音，未将这些算作新起音；录音开头已经在响，也不测第一次拨弦延迟。
- 后段有实际约 82 Hz 的低频与谐波，用户确认最后乱弹；不能按“全部应该是 A3”打分。

**此次 A3 稳态音高/八度通过；瞬态显示与低延迟仍未完成验收。第 3 弦第 7 品 D4、连续旋律、双音/三音不在本次通过范围。**
