## 0.2.4 当前行为：完整区域发声与实际按音白环

本节覆盖下方旧版的“代表指型、四品区域、仅候选显示、指型外圈”规则；旧记录保留用于追踪。

- **K = Guitar**：选定基准品与后两品，共三个品位（例如 6–8 品）。收集标准调弦六弦在该区域内的
  全部当前和弦音，按绝对 MIDI 音高去重，全部同时发声；同名不同八度分别保留。
  不再限制三个剩余手指、每弦一个音、连续发声弦或六音上限。区域是练习音集，**不是保证可同时按住的实体指法**。
- **H/L**：按住和弦时向低/高候选把位移动，先释放旧音再发新音；到边界不重触发。
  **J = Piano**，保持原有紧密排列、独立记忆与转位逻辑。Tab 继续切换三/七/九和弦。
- 七和弦仍使用用户指定的四类位置族并移调；三/九和弦从 1–14 品候选中选择。
  所有类型都剔除相差一品的相邻候选：优先保留区域内和弦音弦/品位置较多者，平手保留低品；间距至少两品。
  因此 C major 的 Bm7♭5 目前保留 **3、6、10、12、14 品**。这是覆盖率筛选，不是已验证的舒适度排序。
  默认仍就近第 11 品；旧项目若保存已被剔除的位置，就近解析，等距取低品。
- 钢琴、吉他、谱面共用高亮规则：普通背景音淡色，当前区域候选较亮，实际按下的调内音最亮且有**白环**。
  白环来自实际电脑和弦或实体 MIDI 的按音状态，不再静态圈出某个代表指型；调外实体 MIDI 音保持灰色。
  所有图中的相同**绝对音高**同步，同音名但其他八度不会无条件亮。
- 白环画在原圆点边界内，不增大到超过黑键宽度。食指上沿空心/实心位置点保留；S/A 柔和配色不变。
- 不做延时扫弦；全部音同一事件位置发出。更多同时音可能更响，先用较低音源/轨道音量试听。
- 21 个 CLAP 参数和 v3 保存格式不变，稳定 ID 不变。`Voice 1..6` 仍只是前六个音的兼容诊断参数，
  不代表 MIDI 总音数；内部容量为 18，当前完整目录最多 9 个不同音高。实体 MIDI 不重新配音。

实现：`guitar.toml` / `generate_guitar.py` / `guitar_table.jsfx-inc` 存区域音高目录；
`guitar.jsfx-inc` 负责查表和导航，`midi.jsfx-inc` 按实际长度发声并释放全部槽位；

## 使用

### 用户指定的七和弦把位（0.2.3）

以下是用户口述的练习位置，不是从乐谱核对的标准 CAGED 指法。
只替换 Guitar 七和弦的位置目录；Piano、三和弦与九和弦保持原行为。

| C major 参考和弦 | 参考位置 | 调内同族 |
|---|---|---|
| Cmaj7 | 0、3、5、8、10、12 | I、IV |
| Dm7 | 2、5、7、10、12、14 | ii、iii、vi |
| G7 | 0、3、5、7、10、12 | V |
| Bm7♭5 | 2、3、6、7、9、10、12（暂定） | viiø |

按目标和弦根音相对参考根音的半音距离平移，再按 12 品重复，保留 1–14 品内的位置。
因此 Bm7♭5 也会出现 14 品（2 品的八度重复）。6/7 品、2/3 品分别保留，不合成虚构的横按。
9 品来自用户前面单独说的位置，后面重复说的 9 更正为 6；该口述仍待实弹确认。
0 品仅保留用户明确指定的 Cmaj7/G7 开放位，不因取模自动添加 Dm7/Bm7♭5 开放位。
开放琴弦不是食指横按；移调后的正品位仍是可移动的封闭指型。

每个位置仍由原有规则选择一个包含完整四音的代表指型；食指位置相同不表示已经复刻
用户的每根弦与每个手指。四品区域内的全部候选和弦音、全指板的同音高亮继续保留，
但不全部同时发出 MIDI。标点、H/L、代表指型和 MIDI 共用同一目录。
旧项目保存的把位若不再可选，取最近位置，等距取较低位置；0 品可保存、重开恢复。

验证：531 项 pytest、6 项 CTest、真实 CLAP probe；12 调 × 7 级的七和弦位置与指型
平移逐项检查，全部 252 种组合 / 1725 个指型的音高、导航与区域显示回归通过。
Bitwig 实测四类参考、IV/iii/vi、Dbmaj7、持音从 0→3→0 品；恢复测试前 Library 设置。
日志、截图及备份：`target/chordlab-user-anchors/`。

右上角 S（Sustain）与 A（Active）为白字方形按钮，柔和红关闭、柔和绿开启，14 px 常规字重。
点击 S 或按 Space 切换延音；A 表示电脑键盘已启用且插件获得焦点，实体 MIDI 不受 A 限制。

插件获得焦点、A 为绿色后：

| 键 | 行为 |
|---|---|
| J | 直接选择 Piano，保持原有紧密排列 |
| K | 直接选择 Guitar，按照标准调弦的封闭指型发出 MIDI |
| H / L | Piano：向低 / 高转位；Guitar：沿指板切换较低 / 较高把位 |
| Z X C A S D F | 6、7、1、2、3、4、5 级，和以前一致 |
| Tab | 三和弦 / 七和弦 / 九和弦，自动保存 |
| Space | Sustain 开 / 关 |

可以按住和弦键，再按 H/L/J/K；不用先松开。G/V 已取消。
谱号旁不再显示 Piano/Guitar 模式点、悬停提示或 `Fret n` 文字，也不保留隐形点击区域。
使用 J/K 切换模式；直接观察音符分布与下述食指位置点即可。

下组吉他指板的**额外浅色外圈**标出当前选定指型；不是说所有彩色圆点都要按。
按住和弦时，实际 MIDI 音高的所有同音异弦位置会一起亮；八度不同不算同一个音。
钢琴和谱面显示相同实际音高。外接 MIDI 仍原样通过，不会被强制重新配成吉他指型。
Guitar 是 voicing 模式，不会自动把下游钢琴/Surge 换成吉他音源。

### 把位内全部和弦候选音（0.2.2）

Guitar 模式的下组指板会突出显示食指基准品至基准 +3 范围内，**全部六根弦上的当前和弦音**。
同一根弦可以有多个备选音，不受当前选定指型的发声弦或三个剩余手指限制；它们是可轮换选择的音，
不是要求一次同时按住。把这些位置得到的**绝对 MIDI 音高**组成集合，在整个指板上所有同音位置同步突出。
同名但不同八度的音，只有自身也在该集合中才突出，不按 pitch class 无条件点亮所有八度。

- 普通和弦背景音：原来的淡色。
- 区域候选音与其同音位置：更亮，即使没有按键也可查看。
- 实际发声音：最亮；浅色外圈仍只表示当前选定指型。

上组音阶图、钢琴和五线谱不加入这种候选高亮，实际发声高亮仍保持原逻辑。
MIDI 输出、指型选择、候选食指位置和保存格式均不变；不会发送额外候选音。
范围来自 `guitar.toml` 的 `fret_span`，亮度来自 `theme.toml` 的 `guitar_candidate_mix`。
例如 Emaj7 第 12 品区域还包含 D 弦第 14 品 E4，虽不在原选定六弦指型中，
现在它和其他弦上同样的 E4 都突出；E2 不会仅因也叫 E 就一起突出。

0.2.2 验证：426 项 pytest、6 项 CTest 和真实 CLAP probe 通过。EEL 对全部 252 种
调/级数/类型组合、每个候选把位逐一枚举六弦四品，再核对 128 个 MIDI 音高的候选集合。
Bitwig 实测持续按键 H/L、J/K、Tab、换调与松键；截图像素检查确认 E4 同音位置颜色一致、
E2 保持淡色、实际发声 E3 更亮、松键恢复候选色。已保存 Library 并恢复可试弹状态。
构建、回归、截图、旧安装件/工程备份：`target/chordlab-region-notes/`。

### 食指位置点（0.2.1）

Guitar 模式下，**下组和弦指板上沿**显示当前和弦可选的食指基准品：空心圆为其他候选，
实心圆为当前选中的位置。大小与指板下方原有单点／双点一致，横向严格对齐所在品格中心。
H/L、换调、换级数、Tab 切换和弦种类或恢复状态后，都从实际 MIDI 指型的同一目录重新计算，
不维护一份独立的 UI 位置。钢琴模式与上组音阶指板不显示这排点；下方固定品位点不变。
这些点仅为位置提示，不是额外音符，也不发送 MIDI；不表示该品上的所有弦都必须横按。

本次仅加入位置显示，仍使用下述第一版候选目录。候选不等于已经过真人确认的顺手指法；
尚未换成精选指型家族，也没有把需要移动手指才能依次弹出的音加入同时发声的和弦。

调/级数/类型组合的每个候选位置，验证仅一个实心点、候选数量一致、H/L 和最近位置解析一致。

## 第一版指法范围

- 标准调弦 E2 A2 D3 G3 B3 E4；指板显示 0–17 品。
- 食指基准品 1–14，食指可单按或横按；其余最多三个手指，每指按一根弦。
  0.2.3 额外支持用户明确指定的 Cmaj7/G7 开放把位 0。
- 基准品至基准 +3（共四品）；连续 3–6 根发声弦，只允许两端闷弦。
- 三 / 七 / 九和弦都保留完整音集，允许重复音与重复八度；同一绝对 MIDI 音高只发一次。
- 每个可用基准品挑一个代表：先偏好根音低音，再较小跨度、较少手指、较完整弦数。
- 默认优先第 11 品；不是硬性要求每个和弦都在 10–12 品。
  少数完整九和弦最近只有第 5–7 品附近候选，此时不为了高把位而省掉五音或九音。
- H/L 到边界停住，不循环跳回、不重新触发同一指型。

这不是“吉他只有某几个品位能横按”的理论限制，而是保守筛选后的代表指型。
除明确指定的 0 品开放位外，不混用高把位与开放弦。
目前不含拇指按弦、无名指小横按、内部闷弦、左手人体工学评分或个性化手跨度。
通过规则不等于每个人实际都能舒服地按；需真人试弹后完善候选排序/白名单。
第 10–12 品与中央 C 不是等价的定位条件，这版优先遵循用户指定的品位区域。
