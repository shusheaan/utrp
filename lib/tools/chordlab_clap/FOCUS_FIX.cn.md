# Keyboard 焦点同步修复 — 0.1.4

[English](FOCUS_FIX.md)

## 原因与行为

原按钮只显示 `enabled`（允许捕获），没有显示实际焦点状态。
现在绿色条件为：允许捕获、编辑器可见、JUCE 子组件有焦点、原生 peer 有焦点。
原生 peer 检查用于避免嵌入式宿主中组件焦点缓存与 OS 焦点不一致。
按键入口、释放轮询和按钮指示共用同一焦点判定。

- 失焦变红，并释放电脑持键；不自动关闭 Sustain，也不改变启用偏好。
- 点击回插件恢复绿色；手动关闭或 Esc 后，单纯恢复焦点不会重新启用。
- 点击失焦造成的红按钮会激活，而不是反向关闭。鼠标按下时记录显示状态，
  避免按住鼠标期间获得焦点后，按钮操作方向翻转。
- 实体 MIDI 处理不依赖按钮或编辑器焦点；本次未修改音乐核心、路由、参数或 state 格式。
