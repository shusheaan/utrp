# utrp 练习指南

[返回首页](../README.md)。以下命令默认在项目根目录执行。
![preview](../preview.gif)

结构化 TUI 和弦进行 / 指板训练器。保留原有 header、progression、target、左右音符与乐器面板、footer 布局，以及 cyan/green/yellow/dark-gray 配色。`preview.gif` 是旧版截图。

## 启动

本机已安装快捷命令，在任意目录输入即可直接进入吉他练习：

```sh
utrp
```

钢琴使用 `utrp --instrument piano`。命令链接到本项目的 release binary，代码更新后需重新 `cargo build --release`。默认读取编译时内置配置；自定义配置仍使用 `--config PATH`。

```sh
cargo run --release                       # 直接开始 guitar
cargo run --release -- --instrument guitar
cargo run --release -- --instrument piano # 选择 MIDI 输入设备
cargo run --release -- --config config/simulate.toml --seed 42
```

建议终端 **120×50**，可同时查看完整双谱表和指板；100×30 使用清楚的文字视图，72×30 为最小尺寸（更小会明确提示放大，避免隐藏操作反馈）。吉他不需要 MIDI，不初始化 MIDI，也不需要外部歌曲或音频设备。钢琴保留 MIDI，按屏幕实际音高/转位匹配；没有设备会明确报错。

## 本次规则速览（2026-10-01）

- **训练范围**：十二主音 × 大小调（Ionian / Aeolian）；完整三和弦、七和弦及实际变音成员，练转位、不同弦组 / 把位、同时手型与分解琶音。保留指板、实际音高五线谱和原 TUI 布局；吉他自我确认，钢琴 MIDI，不做音频识别。
- **闭环底座**：保留原 40 项序列；自动转调只在走完闭环且满足最少停留后发生，默认概率 50%，题量超容差时优先转出。小调内可用 V7→i，不增加第三个 mode。
- **转调与接近**：直接属七 / 共同和弦 / 减七三条可行路线随机使用；同主音大小调互换也在候选池。副属七、替代属七、SD25、SSD25 默认互斥概率 10% / 5% / 10% / 5%，解决到原定目标后继续闭环，不等于转调；ambient / 调内借用扩展先关闭。
- **手动 E / Q**：E 欠练优先、同量随机转调；Q 返回上一个调（不是固定开局调）。在当前 A 按键：先弹下一和弦 B，B 结束后启动转调；接近链 / 桥接 / 明确 V7→I/i 必须解决完。重复请求只更新、不叠加。手动可放弃旧闭环剩余内容，**不保存进度**；新调主和弦是新闭环第 1 项，不再手动就正常走圈。
- **本次平衡**：按主音 × mode 累计实际新题量，预览和历史回看不累计，重启清零；默认容差 40 题，自动 Back 优先概率 20% 且受容差限制。显式 Q 可例外返回欠练排序之外的前调；不停 Q 不保证均衡，E / 自动探索会继续补欠练调。把位也按各类任务的练习段数轮换，而非一直就近。
- **最简操作**：直接 `utrp`；默认 10 秒 / 和弦，W 加速、S 减速（下题生效），A/D 回看或跳过，Space 期限内自我确认 + 下一题；超时不计分。Enter / Ctrl-C 停止并总结，无总时长；**Q 不再退出**。

## 控制与计分

| 键 | 作用 |
|---|---|
| **W / S** | 加快 / 减慢；默认每次改变 1 秒，下个和弦生效 |
| **A / D** | 上一个 / 下一个和弦；不计分，不重抽历史目标 |
| **E / Q** | 排队平衡随机转调 / 返回前调；下一个和弦结束且整链解决后执行 |
| **Space** | 表示“已找到”，期限内确认 +1，然后下一个 |
| **Enter** | 立即停止并输出总结；没有总时长或固定题数限制 |
| P | 暂停 / 恢复，保留剩余时间 |
| M | 自动 / 手动切换；手动不限时，切回自动重新计时 |
| Ctrl-C | 与 Enter 一样结束并总结 |

- 默认 **10 秒一个和弦**。到期没有 Space / MIDI 匹配则记 timeout，自动进入下一个，不计分；恰在 deadline 按 Space 也不计分，不误确认下一题。
- 同一目标只结算一次；A 回看已完成、跳过或超时的目标可再练，但不能补刷分。D 跳过不计分。支持增强键盘协议的终端中 repeat/release 不连跳；旧式终端若只报告普通字节，无法可靠区分长按与多次按下。
- 总结包含确认数、MIDI 匹配数、超时、跳过、未完成、练习时长和速度。`Score /100 = (Space 确认 + MIDI 匹配) / (确认 + 匹配 + 超时 + 跳过)`；Enter 结束时尚未到期的当前题不计入分母。
- 吉他 Space 是**自我确认**，不是程序检测弹对；展示覆盖不是掌握度。钢琴匹配实际 MIDI 音高，不只匹配 pitch class。

## 吉他练习配置

- **一个 simulate，两个 mode**：十二主音 × Ionian / Aeolian（大调 / 小调），调内主体练三和弦、七和弦及实际 `1/b3/3/b5/5/b7/7` 成员；转调桥接可用属七、共同和弦及含 `bb7` 的全减七。不要求先背其他 modes；开启副属、替代与 ii–V 接近链，ambient / 借用色彩仍关闭。
- **原闭环是底座**：保留原 40 项级数序列，分段预览不改变顺序；自动仅在完整走完闭环后概率转调；手动 E/Q 可例外中断。小调保留自然小调和弦，并在骨架 `5→1` 处概率使用明确标注的 `V7→i`，不是增加第三个 mode。
- **真实指板结构**：完整三音 / 四音和弦、转位、弦品、实际音高、成员、指法和横按；DETACHED 逐音释放，与同时按住的手型分开。结构经过约束检查，但不是人工逐形认证；不舒适时调整范围，不强按。
- **就近与探索兼顾**：同区域优先欠练弦组 / 转位，再选欠练具体手型，最后比较就近连接；每类任务在一个区域默认练 2 段再换区。琶音交替使用探索路径与就近路径，不会永远锁在一个把位。
- **纯基础训练**：无外部歌曲、练耳测验或四套 preset；App 不播放声音。吉他 Space 自我确认，钢琴保留 MIDI；练习记录表示呈现 / 确认，不等于已经掌握。

编辑 [`config/simulate.toml`](../config/simulate.toml) 后用 `utrp --config config/simulate.toml` 加载；直接 `utrp` 使用编译时内置默认。主要参数：

| 参数 | 默认 | 含义 |
|---|---|---|
| `simulation.keys / modes` | 十二主音 / 两个 mode | 整局候选池 |
| `progression` | `original_cycle` | 原闭环底座；兼容选项 `modal_phrases` 才使用短句库 |
| `cycle_chunk_size` | 5 | 每段骨架项数，1–8；分段不重置闭环 |
| `seventh_probability` | 0.5 | 每段选择七和弦的概率；否则三和弦 |
| `minor_dominant_probability` | 0.7 | 小调骨架 `5→1` 改用升导音的 `V7→i`；0 为自然小调 v |
| `modulation_probability` | 0.5 | 圈末正常转调概率；练习量超容差时优先转出；0 明确禁用自动转调 |
| `modulation_methods` | `["dominant", "shared_chord", "diminished"]` | 大小调可用转调路线；先选欠练的可达调，再从该调可用路线中随机选 |
| `modulation_return_probability` | 0.2 | 前调可达、练习量未超容差且上一跳非返回时，20% 优先返回；否则补欠练调 |
| `key_balance_tolerance` | 40 | 各调新题量容差；影响圈末优先转出与 Back，不是逐题差距的硬上限 |
| `minimum_phrases_in_key` | 2 | 自动转调最少停留段数，不能绕过完成闭环；手动 E/Q 不受此门槛限制 |
| `guitar.phrases_per_region` | 2 | CHORD / DETACHED 各自计段，练够再轮换区域；不是熟练度判断 |
| `arpeggio_every` | 5 | 每 5 段安排 1 段 DETACHED；0 只练 CHORD，1 只练 DETACHED |
| `regions` | 0–5 / 4–9 / 8–13 / 12–17 / 16–22 | 把位区域，邻接区域允许重叠 |
| `triad_strings / seventh_strings` | 配置所列弦组 | 实际参与枚举的三弦 / 四弦组合 |
| `extensions / ambient` | false / false | 暂不启用后期扩展；实现保留 |
| `approaches` | true | 独立启用四类接近链，不需要开启 ambient 或借用 |
| `secondary_probability / substitution_probability` | 0.10 / 0.05 | 副属七 / 替代属七接近原定目标 |
| `sd25_probability / ssd25_probability` | 0.10 / 0.05 | ii7 或 iiø7–V7 / 相关 ii7–subV7 接近原定目标 |

默认 `2 段 × 5 项` 大约是每类任务在一个区域练 10 个骨架目标；接近链、闭环末段、转调 bridge 会改变实际题数。DETACHED 插入时可以显示它自己的区域，返回 CHORD 后继续 CHORD 的轮换。回看历史不重新抽手型，也不消耗新目标覆盖。

### 接近链：插在原定和弦转换之间

原来 `C → Am`，抽到 SD25 时变为 `C → Bm7b5 → E7 → Am`；抽到 SSD25 时为 `C → Fm7 → Bb7 → Am`。到达原定 Am 后继续闭环，不因此改变当前调。SD25 根据目标性质选大调 `ii7–V7` 或小调 `iiø7–V7`；SSD25 是替代属七的相关 `ii7–subV7`，不是仅把 SD25 中的 V 替换掉。

四种接近概率互斥，默认合计 30%，其余直接连接；这是可插入目标处的抽样概率，不是全部事件的占比。减／增／sus 等不适用目标不强加接近链；开局首和弦不加前缀，转调桥接与明确的大小调 V7→I/i 不嵌套插入。整条接近链和目标一起入队，不会中途转调。骨架的顺序和级数边保留，但插入处不再是两个骨架和弦直接相邻。

每个插入和弦同样有真实吉他目标、五线谱、倒计时、Space 计分与本次调量统计。`approaches=false` 且 `extensions=false` 可恢复无接近链；旧配置省略新字段时保持关闭、新二五概率为 0。兼容旧配置的 `extensions=true` 也可开启接近链和借用；四种接近概率加 `borrow_probability` 必须有限、非负且总和不超过 1，借用仍只在 extensions 开启时生效。

[`config/progressions.toml`](../config/progressions.toml) 保留原 `cycle`，也保留非默认 modal 短句库；可用 `--templates PATH` 定制。原序列包含 39 次相邻转换、29 种不同有向级数边，首尾主和弦共享，连续两轮不额外插入 `1→1`。**保留原闭环不等于证明它是所有风格的唯一最小闭环**，也不把大小调的同一级机械解释成相同功能。

大小调转调始终通过新调 `V7→tonic` 建立中心，再继续新调闭环；它不是只改调名，也不受调内 `extensions=false` 限制。现有三条路线：

- **直接属七**：新调 `V7→I/i`。
- **共同和弦**：匹配旧、新调的完整同根同性质三和弦或七和弦；优先使用刚弹过的完整和弦，否则插入一枚共同和弦。显示旧、新级数，再接新调 `V7→I/i`，不把只有三音相同的不同七和弦当作同一和弦。
- **减七转调**：旧调导音全减七等音重解释为新调导音全减七，接新调 `V7→I/i`。严格保留四个 pitch classes，只在确有重解释路线时使用；如 C 大调的 `Bdim7`（B D F Ab）重解释为 Eb 小调的 `Ddim7`（D F Ab Cb），接 `Bb7→Ebm`。大调中的该全减七属于借用色彩，小调涉及升导音；不是自然音阶内的半减七，也不是任意根音的 dim7 都能转去任意调。

**自动 Back 返回**是目的地策略，不是第四种桥接：返回上一次所在调（不是固定开局调），仍使用上述可行路线。返回后下一跳恢复欠练优先选择，避免主动连续来回；只有两个可达调时仍会自然交替。首次转调没有前调，不会触发 Back。返回前调的题量不得比当前可达候选中的最少量多出 `key_balance_tolerance`；默认返回概率并非不受约束的固定实际返回比例。所有自动转调仍须走完闭环；手动例外见下方。

### 手动转调：E 随机，Q 返回

- **E** 从配置允许、路线可达且不同于当前调的候选中，选择本次新题量最少的调，同量随机；不套用自动 Back 的 20% 优先规则。**Q** 回到紧接当前调之前的调，仍使用配置允许的桥接；可连续手动往返，不受自动 Back 的题量容差限制。
- 在 A 按 E/Q，不改 A，也不立刻替换已预览的 B：B 成为当前题后显示 `after CURRENT`，B 完成后才开始桥接。若 B 是接近链、转调桥接或明确 V7→I/i 的中间和弦，延后到整链落点结束；不是要求 B 在当前调恰好能作为共同和弦。新路线会在需要时插入合法 pivot，再以新调 V7→I/i 到达主和弦。
- 只保留一个待执行请求；后按的有效 E/Q 覆盖类型，**不重置等待边界**。等待期间抑制自动转调。执行时丢弃旧闭环未呈现内容，不保留待续进度；桥接落点为新调闭环 `1/40`，后续继续第 2 项。频繁手动中断会少练后半圈；丢弃项不计覆盖，要全面练到骨架仍需让自动流程走完圈。
- 初次 Q 没有前调，或配置没有可行路线：明确提示、不转调、不退出；无效请求不取消已有有效请求。A 回看历史时不接受新转调请求，先 D 回到最新目标；回看也不会重复生成或计数。
- E/Q 本身不推进、不计分、不重置倒计时；暂停时可排队，暂停本身不推进。Space、D、正常超时均可推进到执行边界；恰在 deadline 的按键按超时优先处理，不误应用到下一题。Enter 结束不额外执行待转调。`modulation_probability=0` 只关自动，E/Q 仍可用。

**本次练习量平衡**：对配置内每个主音 × mode 分别累计实际推送的新目标（桥接计入其标注的新调）；不是进入某调的次数。调内 CHORD/DETACHED 都按一题计数，跳过/超时也属于已分配题目，不代表成功或熟练。预览、A/D 回看、暂停、调速不重复累计；重启从零开始，不读历史日志。

转调时优先实际题量最少的可达调，同量随机；若当前调题量比配置池最低量多出默认 40 题，则满足圈末和最少停留条件后优先转出，不再等待概率命中。`modulation_probability=0` 仍完全关闭自动转调。自动完整闭环及所有桥接必须走完，故短时间差距可能超过 40，长期才趋于均衡，不承诺每时刻完全相等或按用时平均。受限路线不连通、固定调池、禁用转调或持续手动 Q 往返不能保证全 24 调均衡。结束总结与 JSONL summary 的 `key_practice` 会列出本次各调题量（含未练到的 0），不恢复到下一局。

只启用共同和弦或减七路线可能缩小可达调集合；默认保留 `dominant`，使所有 24 个大小调组合可达。找不到允许路线时明确留在原调，不暗中启用禁用路线。未写新参数的旧配置兼容原来的 `dominant` 单路线与返回概率 0。若手动加入其他 modes，则仍使用原有 modal 短句及共同音中心切换，不将大小调路线机械套入；上述路线列表控制功能性目标调。

## 怎么看界面

- 顶部显示当前 key/mode；转调时显示 `旧调 => 新调`，下方是音阶及整个已计划短句的和弦序列。黄色 `[当前和弦]`、灰色过去、白色未来；预览不计分、不推进生成器。短句不是带节奏的完整小节乐谱。
- `Cycle 2 16/40` 表示当前调第 2 轮闭环的第 16 项；`V7/i` 是小调内属七解决，`V7/new` 才是准备新调。
- `pivot/级数` 表示共同和弦，绿色说明显示 `old ... = new ...`；`dim7/new` 表示等音重解释的减七，说明显示旧、新拼写；`V7/back` / `Return to previous key` 表示桥接返回前调。这些目标同样有吉他手型/琶音与五线谱。
- `ii/target` / `V7/target` 是 SD25，`ii/subV` / `subV/target` 是 SSD25；绿色说明显示整条链及目标，不标成新调。长进行按完整和弦标签换行并随当前目标滚动；行首 `<` / `>` 提示前／后还有隐藏内容，操作反馈保留独立位置。
- 青色 `Pending E balanced / Q back` 是待执行请求；`after NEXT` 表示还要先练下一题（遇链延后），`after CURRENT` 表示当前题结束后执行。`Manual E/Q: 旧调 -> 新调` 记录最近一次手动转调；实际当前调始终看顶部 Key。
- `PLAY` 显示目标、剩余时间及 CHORD/DETACHED/MIDI；`Chord tones` 显示实际和弦音与 `b3/#11` 等音程。
- Guitar 的弦号 `6→1` 为低音弦到高音弦，显示品位、实际音名、音程、手指、根音弦和低音；`x` 表示静音。DETACHED 按编号逐音弹奏并释放，不是同时按住。
- Staff 为 **concert-pitch 高低音双谱表**：C4 是中央 C，超出谱表用加线；每音显式标 `♮/♯/♭`，支持双升降，不使用隐含调号。吉他显示实际发声音高，不采用传统吉他高八度记谱。空间不足会明确切换文字视图，不静默裁掉音。

```sh
lib/tools/simulate/target/release/utrp-sim --events 100 --seed 42
```

同配置 / seed / instrument 的两个 headless 入口输出一致，TUI 消费同一个 `PracticeStream`。一条导出记录 = 一个实际和弦事件（包括 bridge），不是一整组 approach。旧 `--measures` 是 `--events` 别名；`--key` / `--mode` 限制整局候选池；`--threshold` 为最少停留短句数。旧 seed shim 不再需要，仍兼容 `UTRP_SIM_SEED`。

JSON 保留 `key/scale/chords/symbol/notes`，增加完整事件、根音、真实吉他结构；guitar 无解时 `notes=[]` 并带原因，不伪造声音。输出保留 `role=target` 供旧消费者使用，真实事件类型见 `kind` / `event.music.role`。
